# Источники по вычислительной эффективности Fleet MPPI

Для обзора статьи исходный алгоритм MPPI и способы организации выборки описаны в [1, 4, 5]. Из работ по геометрии ближе всего VAMP с пакетными проверками на CPU [2] и EXACT-MPPI с полигональным контуром наземного робота [3]. В EXACT-MPPI расстояние вычисляют по облаку точек на GPU. В Fleet MPPI критерием эквивалентности служит ответ штатного CostCritic на той же клеточной карте. Сравнивать время этих двух методов напрямую можно только после согласования входных данных и требуемого результата.

1. Williams, G. Model Predictive Path Integral Control: From Theory to Parallel Computation / G. Williams, A. Aldrich, E. A. Theodorou // Journal of Guidance, Control, and Dynamics. — 2017. — Vol. 40, no. 2. — P. 344–357. — DOI: [10.2514/1.G001921](https://doi.org/10.2514/1.G001921).
2. Thomason, W. Motions in Microseconds via Vectorized Sampling-Based Planning / W. Thomason, Z. Kingston, L. E. Kavraki // 2024 IEEE International Conference on Robotics and Automation (ICRA). — IEEE, 2024. — P. 8749–8756. — DOI: [10.1109/ICRA57147.2024.10611190](https://doi.org/10.1109/ICRA57147.2024.10611190).
3. EXACT-MPPI: Exact Signed-Distance Navigation for Arbitrary-Footprint Robots from Point Clouds via Path Integral Control / C. Peng, Z. Ge, W. Lu [et al.] // arXiv. — 2026. — Препринт, версия 2. — URL: [https://arxiv.org/abs/2605.29663v2](https://arxiv.org/abs/2605.29663v2) (дата обращения: 21.11.2026).
4. MPPI-Generic: A CUDA Library for Stochastic Trajectory Optimization / B. Vlahov, J. Gibson, M. Gandhi, E. A. Theodorou // arXiv. — 2026. — Препринт, версия 4. — URL: [https://arxiv.org/abs/2409.07563v4](https://arxiv.org/abs/2409.07563v4) (дата обращения: 21.11.2026).
5. Trevisan, E. Biased-MPPI: Informing Sampling-Based Model Predictive Control by Fusing Ancillary Controllers / E. Trevisan, J. Alonso-Mora // IEEE Robotics and Automation Letters. — 2024. — Vol. 9, no. 6. — P. 5871–5878. — DOI: [10.1109/LRA.2024.3397083](https://doi.org/10.1109/LRA.2024.3397083).
6. Model Predictive Path Integral Controller // Nav2 Documentation. — URL: [https://docs.nav2.org/configuration/packages/configuring-mppic.html](https://docs.nav2.org/configuration/packages/configuring-mppic.html) (дата обращения: 21.11.2026).

Предварительный расчёт ориентированных контуров можно сопоставить с [реализацией GridCollisionChecker в Smac](https://github.com/ros-navigation/navigation2/blob/bdb75f435ecb79d92266060801ba6d95e23447db/nav2_smac_planner/src/collision_checker.cpp). Значения CPU и результаты проверки совпадений получены в [собственных экспериментах](../nav2/current/).
